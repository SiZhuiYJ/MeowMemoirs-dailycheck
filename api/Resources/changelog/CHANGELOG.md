## [1.5.0] - 2026-11-21

### 新增

- 课表导入会先尝试读取文件里的作息时间表（如 Excel 的「第1节 08:00-08:45」）；文件里没有时，可在预检弹窗中选用已保存的作息、恢复默认作息，或直接编辑（增删节次、修改起止时间）
- 新增「作息表」管理：Web 课表页与小程序课程 tab 都可新建 / 修改 / 删除作息表模板，并复用从已有课表提取的历史作息；新建 / 设置课表时可直接套用一套作息
- 导入预检支持编辑：Web 与小程序都能在保存前修改课程时间段（星期 / 节次 / 周次 / 地点 / 教师）和作息，确认无误后再命名保存
- 小程序课程 tab 升级为可编辑：支持新建 / 修改课表、添加 / 编辑课程，并可管理作息表（此前只能查看）

### 优化

- 作息节数与课程节次自动对齐：文件作息比课程短时自动补齐默认时间；选中一套多节作息（如 12 节）但课程只排到 6 节时也会完整保留整套作息
- 导入确认接口保留完整作息节数，不再按课程用到的最大节次截断；预检新增「作息是否来自文件」标识，便于前端提示
- 课表 / 作息表的写接口关闭自动重试，避免网络抖动时重复创建

### 修复

- 修复导入文件没有作息时只能使用默认作息、无法复用历史作息的问题
- 修复小程序课表页无法新建 / 修改课表与课程的问题

## [1.4.0] - 2026-11-21

### 新增

- 课表导入支持截图 / PDF：Web 与小程序都可上传 .pdf / .png / .jpg / .jpeg / .webp / .bmp，服务端用 OCR 识别课表；识别结果先进入预检让用户核对后再保存（OCR 可能有错别字，请重点核对课程名、地点与教师）
- 小程序「导入」支持聊天里的图片消息，课表截图可以直接选来导入
- 新增「按预检结果保存」接口：OCR 确认后直接提交预检数据入库，不用重复识别、不用重复上传
- Web 全站弹窗统一为 AppDialog：主题色渐变底、悬浮毛玻璃顶 / 底栏、高度随内容自适应，嵌套弹层、ESC / 遮罩关闭与键盘焦点管理内置；聊天、顶栏、主题色、课表页弹窗视觉与交互统一

### 优化

- Excel 与 OCR 共用同一套「文字网格 → 课表」解析逻辑，两种来源识别结果更一致
- 导入入口按文件类型自动分流：Excel 先预检再重新上传保存，截图 / PDF 走 OCR 预检后直接保存；导入按钮会提示 OCR 耗时（约 5~15 秒）
- 文件限制更明确：Excel ≤10MB，截图 / PDF ≤30MB，不支持的类型直接提示
- 手机端弹窗不再出现「弹窗里套滚动条」的双层滚动，长列表改为弹窗内容区单层滚动

### 修复

- 修复小程序「导入」只能选择聊天文件、选不到聊天图片（课表截图）的问题
- 修复 Web 聊天弹窗在窄屏下宽高不自适应、内容被截断的问题

## [1.3.2] - 2026-11-20

### 新增

- 意见反馈：Web 与小程序设置页可提交意见（内容 + 可选联系方式），并在「我的反馈」查看提交记录、处理状态（待回复 / 已回复）与管理员回复

### 优化

- GET /mm/Auth/me 与登录 / 注册 / 刷新等认证响应新增 role 字段（user / admin），前端据此区分普通用户与管理员入口

## [1.3.1] - 2026-11-20

### 新增

- 课表导入改为两步：先「预检」只解析不写库，确认识别结果并填写课表名后再正式导入，Web 与小程序同步
- 预检会展示解析出的课程明细、周数与节次、作息时间，并列出需要核对的提示（缺教师 / 缺地点 / 缺周次 / 使用默认日期与作息）与时间冲突（同一天、节次重叠、周次有交集），有冲突仍可继续导入
- 第三方账号绑定页重做：增加绑定状态总览、渠道中文名、绑定日期与「已绑定 / 未绑定 / 暂未开放」区分，个人主页同步显示已绑定的具体渠道

### 优化

- 课表导入的缺省信息更透明：默认课表名、默认开课日期、默认作息时间都会在预检里提示，便于导入前核对
- 小程序令牌刷新改为全局单飞：并发多个 401 只刷新一次，避免互相把会话挤掉；对「401 代表业务错误」的接口可跳过自动刷新
- 第三方绑定 / 解绑增加二次确认与按钮 loading，操作期间禁用按钮，避免重复提交

### 修复

- 修复微信绑定失败时可能反复刷新令牌、消费同一个一次性 code 并出现刷新死循环的问题
- 修复第三方绑定页绑定日期显示 NaN-NaN-NaN 的问题（完整时间戳按本地时区格式化）
- 修复个人主页「第三方账号绑定」只显示数量、看不到具体渠道的问题

## [1.3.0] - 2026-11-20

### 新增

- 课表支持从 Excel 导入：Web 课表页点「导入课表」选择 .xlsx / .xls，服务端解析后新建课表并自动切换
- 小程序课程 tab 顶栏新增「导入」：从微信聊天记录选择 Excel 上传，导入成功后自动刷新并切换到新课表
- 解析兼容通用横排课表与教务系统竖排课表（合并单元格、一格多课、相邻同门课合并），缺少的作息 / 周数 / 开课日期按默认值补齐

### 优化

- 导入接口限制单文件 10MB、仅支持 .xlsx / .xls（.csv 请先用 Excel 另存为 xlsx），解析失败直接返回可读的中文原因
- 小程序课程 tab 顶栏重新分配宽度：课表名按窗口与右上角胶囊位置自动截断，窄屏下不再挤压「导入 / 今天」按钮

## [1.2.0] - 2026-11-19

### 新增

- 课表：Web 端可新建 / 编辑 / 删除课表与课程（多课表、周次切换、作息时间表、课程颜色 / 地点 / 教师 / 备注、本周课程列表），小程序「课程」tab 只读展示同一份课表数据
- 设置页新增「更新日志」：小程序与 Web 均可查看本页内容，数据来自公开接口 GET /mm/Changelog，无需登录
- 登录记录升级为设备列表：按设备归并展示、标记「当前设备」，并显示每台设备的最近活跃时间（打开小程序 / 网页时自动上报）
- 个人主页支持自定义头像卡背景图，可上传、恢复默认，Web 与小程序同步；未设置时回退用头像图作背景
- 头像修改新增「使用上次头像」：当前头像与上次头像可来回切换，无需重新上传
- Web 首页顶栏新增首页快捷入口，用户菜单新增「课程表」；Web 用户主页头像卡改为与小程序一致的背景卡样式

### 优化

- 背景图上传保留 1:1 裁剪后的原始像素：已是 WebP 的直接存储（不重新编码），其它格式仅转 WebP 不缩放；上限放宽到 20MB / 最长边 8192px，Web 端上传前先转 WebP 减少传输体积
- 背景图转码只解码一次并用 Rgba32 编码，降低大图内存峰值，避免部分 Android 机型转码时原生崩溃
- 登录记录接口按设备聚合（一次查询关联设备与最后一条登录记录），计数改为设备数，列表按最近活跃时间排序
- 客户端统一携带持久化设备标识（Web 存 localStorage、小程序存本地存储），后端缺失时用 UA 指纹兜底，登录与活跃归并到同一台设备
- 小程序 HTTP 4xx 业务错误不再自动重试，避免「微信 code 只能消费一次」这类接口被重试后失效
- 更新日志长内容折叠为 3 行（最新版本默认展开，其余可展开 / 收起），并支持下拉刷新与失败重试
- 微信绑定失败时优先展示服务端返回的具体原因（如该微信已绑定其他账号）
- 小程序图片组件形成独立堆叠上下文，头像编辑按钮不会再被背景图遮挡；头像与背景的点击互不误触

### 修复

- 修复微信绑定冲突时提示不准确，以及重试一次性 code 导致 409 被误报成 401 的问题
- 修复个人主页点头像误触发背景预览、背景图盖住头像编辑遮罩的问题
- 修复小程序背景图裁剪固定 1200px 导致大卡片发虚的问题（按原图短边裁剪，保留原始像素）
