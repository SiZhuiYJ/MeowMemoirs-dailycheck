## [1.3.0] - 2026-11-20

### 新增

- 课表支持从 Excel 导入：Web 课表页点「导入课表」选择 .xlsx / .xls，服务端解析后新建课表并自动切换
- 小程序课程 tab 顶栏新增「导入」：从微信聊天记录选择 Excel 上传，导入成功后自动刷新并切换到新课表
- 解析兼容通用横排课表与教务系统竖排课表（合并单元格、一格多课、相邻同门课合并），缺少的作息 / 周数 / 开课日期按默认值补齐

### 优化

- 导入接口限制单文件 10MB、仅支持 .xlsx / .xls（.csv 请先用 Excel 另存为 xlsx），解析失败直接返回可读的中文原因
- 小程序课程 tab 顶栏重新分配宽度：课表名按窗口与右上角胶囊位置自动截断，窄屏下不再挤压「导入 / 今天」按钮

## [1.2.0] - 2026-11-19

### 新增

- 课表：Web 端可新建 / 编辑 / 删除课表与课程（多课表、周次切换、作息时间表、课程颜色 / 地点 / 教师 / 备注、本周课程列表），小程序「课程」tab 只读展示同一份课表数据
- 设置页新增「更新日志」：小程序与 Web 均可查看本页内容，数据来自公开接口 GET /mm/Changelog，无需登录
- 登录记录升级为设备列表：按设备归并展示、标记「当前设备」，并显示每台设备的最近活跃时间（打开小程序 / 网页时自动上报）
- 个人主页支持自定义头像卡背景图，可上传、恢复默认，Web 与小程序同步；未设置时回退用头像图作背景
- 头像修改新增「使用上次头像」：当前头像与上次头像可来回切换，无需重新上传
- Web 首页顶栏新增首页快捷入口，用户菜单新增「课程表」；Web 用户主页头像卡改为与小程序一致的背景卡样式

### 优化

- 背景图上传保留 1:1 裁剪后的原始像素：已是 WebP 的直接存储（不重新编码），其它格式仅转 WebP 不缩放；上限放宽到 20MB / 最长边 8192px，Web 端上传前先转 WebP 减少传输体积
- 背景图转码只解码一次并用 Rgba32 编码，降低大图内存峰值，避免部分 Android 机型转码时原生崩溃
- 登录记录接口按设备聚合（一次查询关联设备与最后一条登录记录），计数改为设备数，列表按最近活跃时间排序
- 客户端统一携带持久化设备标识（Web 存 localStorage、小程序存本地存储），后端缺失时用 UA 指纹兜底，登录与活跃归并到同一台设备
- 小程序 HTTP 4xx 业务错误不再自动重试，避免「微信 code 只能消费一次」这类接口被重试后失效
- 更新日志长内容折叠为 3 行（最新版本默认展开，其余可展开 / 收起），并支持下拉刷新与失败重试
- 微信绑定失败时优先展示服务端返回的具体原因（如该微信已绑定其他账号）
- 小程序图片组件形成独立堆叠上下文，头像编辑按钮不会再被背景图遮挡；头像与背景的点击互不误触

### 修复

- 修复微信绑定冲突时提示不准确，以及重试一次性 code 导致 409 被误报成 401 的问题
- 修复个人主页点头像误触发背景预览、背景图盖住头像编辑遮罩的问题
- 修复小程序背景图裁剪固定 1200px 导致大卡片发虚的问题（按原图短边裁剪，保留原始像素）

## [1.1.0] - 2026-11-15

### 新增

- 小程序全面接入单色主题：强调色种子实时推导色阶，支持日间 / 夜间切换
- 小程序自定义毛玻璃导航栏，页面标题与状态栏统一适配
- Web 打卡详情图片支持全屏预览，音频播放器按封面取主题色
- Web 设置菜单与顶栏用户菜单统一为 SettingsMenu 组件

### 优化

- 小程序开发环境自动探测后端地址，切换网络 / 网段后无需改配置
- Web 全局点击波纹、文件预览悬浮工具栏、诊断页 PC 宽屏两栏布局
- Web 首屏预构建裸依赖，Vite 启动后不再运行时重新打包

## [1.0.1] - 2026-11-08

### 新增

- 聊天文件上传全流程埋点与移动端诊断页
- 生产环境前端 history 路由刷新回退到 index.html

### 优化

- 聊天 / 收件箱 / 日历接口启用 Brotli / Gzip 响应压缩
- 每个请求只解析一次 JWT，减少重复解码
- 建表 SQL 按用户 / 聊天 / 打卡三个业务域拆分

### 修复

- 服务端时间戳统一按 UTC 解析，修复相差 8 小时与撤回窗口失效
- 图片上传落地只保留一条气泡，不再出现「两条又消失一条」
